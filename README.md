## 実装した内容

- Tweet のブックマーク機能を作成した．

## デプロイ先の URL または画面収録したファイル名

レコーディング 2025-09-30 211249.mp4

## 操作手順

1. 各 Tweet の詳細画面、一覧画面、検索画面、プロフィール画面で「Bookmark」ボタンをクリックすると、そのツイートをブックマークに追加できる．
2. ブックマーク済みのツイートには「Unbookmark」ボタンが表示され、クリックするとブックマークから削除される．
3. 画面上部のナビゲーションの「ブックマーク」をクリックすると、自分がブックマークしたツイート一覧をページネーション形式で確認できる．

## 工夫した点

- ユーザーとツイートの多対多リレーションシップを使用してブックマーク機能を実装した．
- 全てのツイート表示画面（一覧、詳細、検索、プロフィール）に統一してブックマーク機能を追加した．
- ブックマーク済みかどうかを視覚的に分かりやすく表示するため、ボタンの表示を切り替えている．

## 苦戦した点

- 多対多のリレーションシップの実装と、各画面でのブックマーク状態の判定ロジックの設計に時間がかかった．
